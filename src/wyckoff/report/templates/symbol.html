吸筹 / 派发
吸筹是大跌之后的横盘，理论上大资金在买；派发是大涨之后的横盘，理论上大资金在卖。两者的规则互为镜像。
阶段 A–E
A 止跌/止涨 → B 区间震荡 → C 测试（Spring/UTAD）→ D 突破 → E 趋势展开。越往后证据越多。
可信度
徽章右边的三个点。一个亮：只有高潮和 AR；两个亮：区间也满了 {{ a.params.range_min_bars }} 根 K 线；三个亮：还出现过测试。
ATR
平均真实波幅，就是这个标的平时一天的波动幅度。工具用“几倍 ATR”来判断一根 K 线算不算特别大，这样贵的股票和便宜的币可以用同一套规则。
量比
当天成交量 ÷ 过去 {{ a.params.volume_period }} 天的平均成交量。2.5 就是平时的两倍半。
{% if a.params.long_baseline_bars %}
长基线
连续暴跌几周后，“平时”的波动和成交量本身已经被抬高，高潮日反而显得不突出。所以工具同时用过去 {{ a.params.long_baseline_bars }} 天的水平再比一次，任一种比法达标都算高潮日。
